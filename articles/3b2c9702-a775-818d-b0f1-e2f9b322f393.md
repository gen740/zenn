# TL;DR

国・地域別トップレベルドメインである ccTLD は、本来の国名とは別の意味で使われることがあります。
`.ai`、`.io`、`.sh`、`.rs` のように、英単語や技術用語、ファイル拡張子として読める ccTLD は、サービスの性格を短い URL で表現できます。
ドメイン名全体を単語やフレーズとして読ませる手法は、一般に「ドメインハック」と呼ばれます。

# ccTLD は国名だけを表すとは限らない

`.jp` や `.uk` のような末尾は、国や地域に割り当てられたトップレベルドメインです。この分類を country code top-level domain、略して ccTLD と呼びます。
ただし、2 文字の組み合わせは国名の略称以外にも読めます。英単語、技術用語、ファイル拡張子、サービス分野を連想できる ccTLD は、本来の地理的な意味を離れて世界中で使われています。
代表例が `.ai` です。IANA 上ではアンギラに割り当てられた ccTLD ですが、現在の Web では Artificial Intelligence の略として自然に読めます。

# 別の意味に読める ccTLD 15選

## `.ai`：Artificial Intelligence

`.ai` はアンギラの ccTLD です。現在は AI 関連企業、モデル、開発者向けサービスなどで広く使われています。
国名を知らない読者には、ほぼそのまま Artificial Intelligence として伝わる強い末尾です。

## `.tv`：television

`.tv` はツバルの ccTLD です。`tv` が television の略として定着しているため、動画配信、放送、映像制作、ストリーミングサービスと相性があります。

## `.me`：自分を表す “me”

`.me` はモンテネグロの ccTLD です。英語の一人称目的格である `me` と一致するため、個人サイト、ポートフォリオ、プロフィールサービスで意味を持たせやすいドメインです。

## `.fm`：FM ラジオ

`.fm` はミクロネシア連邦の ccTLD です。FM 放送を連想できるため、ラジオ局、音楽配信、ポッドキャスト、音声サービスで使いやすい末尾です。

## `.gg`：good game

`.gg` はガーンジーの ccTLD です。オンラインゲームでは、対戦後のあいさつとして `GG`、つまり good game が広く使われています。
そのため、ゲーム関連サービス、e スポーツ、コミュニティサイトとの相性がよい ccTLD です。

## `.io`：Input/Output

`.io` はイギリス領インド洋地域の ccTLD です。計算機分野では Input/Output の略として読めるため、開発者向けツール、SaaS、スタートアップで頻繁に使われています。
文字数が短く、技術的な印象を持たせやすいことも普及の理由です。

## `.sh`：シェルスクリプト

`.sh` はセントヘレナの ccTLD です。Unix 系 OS では、シェルスクリプトのファイル名に `.sh` がよく使われます。
CLI ツール、シェルスクリプト配布サイト、開発者向けサービスでは、URL 自体を技術用語として読ませられます。

## `.to`：英語の前置詞 “to”

`.to` はトンガの ccTLD です。英語の `to` と一致するため、`go.to` のように、ドメイン名全体を短いフレーズとして構成できます。

## `.cc`：略語を自由に割り当てやすい

`.cc` はココス諸島の ccTLD です。`CC` は文脈によって Creative Commons、cycling club、community center など複数の意味に読めます。
特定の一語に固定されないため、組織名やサービス名の頭文字として転用しやすい末尾です。

## `.rs`：Rust のソースファイル

`.rs` はセルビアの ccTLD です。Rust のソースファイルは通常 `.rs` という拡張子を使います。
Rust のライブラリ、開発者ツール、コミュニティサイトでは、プログラミング言語との関連を URL だけで示せます。

## `.it`：it と Information Technology

`.it` はイタリアの ccTLD です。英語の代名詞 `it` と一致し、さらに Information Technology の略としても読めます。
文章の一部として組み込む用途と、IT 関連サイトを示す用途の両方が考えられます。

## `.in`：英語の前置詞 “in”

`.in` はインドの ccTLD です。英語の `in` と一致するため、短い句や命令文の一部としてドメイン名に組み込めます。

## `.is`：英語の be 動詞 “is”

`.is` はアイスランドの ccTLD です。英語の `is` と一致するため、`name.is` のように、ドメイン名全体を文として読ませる構成に向いています。

## `.so`：共有ライブラリ

`.so` はソマリアの ccTLD です。Unix 系 OS では、共有オブジェクト形式のライブラリに `.so` という拡張子が使われます。
低レイヤーのソフトウェア、ライブラリ、開発者向けプロジェクトでは技術的な含意を持たせられます。

## `.ly`：英単語の語尾

`.ly` はリビアの ccTLD です。英語の副詞に多い `-ly` と同じ綴りなので、ドメイン名の前半と組み合わせて一語に見せられます。
代表的な発想は `bit.ly` のように、ピリオドを無視すると単語やブランド名として読める構成です。

# ドメインハックは URL 全体を読ませる

ccTLD を本来の国・地域とは別の意味で使う発想は、広い意味でドメインハックと呼ばれます。
より厳密には、ドメイン名と TLD の境界をまたいで一つの単語やフレーズを作る手法を指します。`bit.ly`、`go.to`、`name.is` のように、ピリオドを含む URL 全体が意味を持つ形です。
一方、AI サービスが単に `.ai` を使う例は、TLD の意味を転用しているものの、必ずしも単語を分割しているわけではありません。それでも、ccTLD の地理的な意味より別の読みを前面に出すという点では、同じ発想に属します。

# ccTLD の正式な意味は変わらない

マーケティング上でどのように読まれていても、IANA 上の分類は変わりません。`.ai` はアンギラ、`.tv` はツバル、`.io` はイギリス領インド洋地域に割り当てられた ccTLD です。
つまり、技術用語として見える末尾にも、必ず元の国・地域があります。ドメインハックの面白さは、DNS 上の正式な分類と、人間が URL から読み取る意味がずれている点にあります。
